The executable now works. The help output shows Typer has collapsed the application into a single command because only `version` exists. We want a stable command group before adding Auth commands.

Add this callback to `cli.py` immediately after creating `app`:

```python
@app.callback()
def main() -> None:
    """Personal notes client for self-hosted Supabase."""
```

The file should be:

```python
import typer

app = typer.Typer(
    name="notes",
    help="Personal notes client for self-hosted Supabase.",
    no_args_is_help=True,
)


@app.callback()
def main() -> None:
    """Personal notes client for self-hosted Supabase."""


@app.command()
def version() -> None:
    """Show the Notes CLI version."""
    typer.echo("notes-cli 0.1.0")


if __name__ == "__main__":
    app()
```

Now verify:

```zsh
uv run notes --help
uv run notes version
uv run pytest
```

The help should list:

```text
Commands:
  version
```
