
## 2. Apply the migration explicitly

```bash
uv run python -c \
  'from pathlib import Path; from notes_bot.database import open_database; path = Path.home() / "Library/Application Support/notes-bot/notes-bot.sqlite3"; connection = open_database(path); connection.close()'
```

This uses the application’s migration mechanism. It does not manually alter the schema.

Alternatively, running the bot and sending `/start` in Telegram will also open the database and apply the migration.
