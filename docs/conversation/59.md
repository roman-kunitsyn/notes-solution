Add a third job to `.github/workflows/ci.yml`, alongside `static-checks` and `database`:

```yaml
notes-cli:
  name: Notes CLI
  runs-on: ubuntu-24.04
  timeout-minutes: 10

  defaults:
    run:
      working-directory: apps/notes-cli

  steps:
    - name: Check out repository
      uses: actions/checkout@v5

    - name: Install uv
      uses: astral-sh/setup-uv@c771a70e6277c0a99b617c7a806ffedaca235ff9 # v9.0.0
      with:
        version: "0.12.7"
        enable-cache: true
        cache-dependency-glob: apps/notes-cli/uv.lock

    - name: Install Python
      run: uv python install

    - name: Synchronize locked dependencies
      run: uv sync --locked --all-groups

    - name: Check formatting
      run: uv run --frozen ruff format --check .

    - name: Run lint checks
      run: uv run --frozen ruff check .

    - name: Run unit tests
      run: uv run --frozen pytest

    - name: Verify CLI entry point
      run: uv run --frozen notes --help

    - name: Build package
      run: uv build
```

This job intentionally does not receive:

- Supabase credentials;
- production secrets;
- network access to your deployment;
- deployment permissions.

It validates the CLI as an isolated package.

## Test the same contract locally

From `apps/notes-cli`:

```zsh
uv sync --locked --all-groups

uv run --frozen ruff format --check .
uv run --frozen ruff check .
uv run --frozen pytest
uv run --frozen notes --help

uv build
```

Inspect the build artifacts:

```zsh
ls -lh dist
```

You should get a wheel and source archive.

The `dist/` directory should remain ignored:

```zsh
git check-ignore dist
```

If it is not ignored, add this to `apps/notes-cli/.gitignore`:

```gitignore
dist/
```

## Commit and push

```zsh
cd ../..

git diff --check

git add \
  .github/workflows/ci.yml \
  apps/notes-cli/.gitignore

git commit -m "Add Notes CLI continuous integration"
git push
```

Then verify all three GitHub jobs:

```text
Static checks
Database migrations and tests
Notes CLI
```

The uv setup is pinned to an immutable action commit and an explicit uv version, while `uv.lock` pins the Python dependency graph. [Official uv GitHub Actions guidance](https://docs.astral.sh/uv/guides/integration/github/).

After CI passes, the next step is the live two-user integration test job for Auth, note isolation, and private Storage isolation.
