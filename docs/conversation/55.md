Add Click as a direct dependency because we now import it directly:

```zsh
uv add click
```

In `cli.py`, add:

```python
from click import edit as edit_text
```

Replace both occurrences of:

```python
edited = typer.edit(
    initial,
    extension=".md",
)
```

with:

```python
edited = edit_text(
    initial,
    extension=".md",
    require_save=True,
)
```

For the edit command, replace:

```python
edited = typer.edit(
    render_draft(
        existing.title,
        existing.content or "",
    ),
    extension=".md",
)
```

with:

```python
edited = edit_text(
    render_draft(
        existing.title,
        existing.content or "",
    ),
    extension=".md",
    require_save=True,
)
```

Then verify:

```zsh
export EDITOR=nvim

uv run ruff format .
uv run ruff check .
uv run pytest

uv run notes create --editor
```

With `require_save=True`:

- `:wq` returns the edited note;
- quitting without saving returns `None`, and the CLI prints `Cancelled`.

Commit the correction:

```zsh
git add apps/notes-cli
git commit -m "Use Click for editor workflows"
```

Click officially provides the temporary-file editor integration used underneath Typer. [Click `edit()` API](https://click.palletsprojects.com/en/stable/api/#click.edit).
