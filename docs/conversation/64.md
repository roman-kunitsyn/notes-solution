“CI passes” means the GitHub Actions workflow succeeds on GitHub.

After pushing the commit:

```bash
git push origin main
```

Open your repository on GitHub and select the **Actions** tab. Find the workflow run for:

```text
Prepare Notes CLI v0.1.0
```

Wait until it shows a green check mark.

You can also inspect it from the terminal if GitHub CLI is installed:

```bash
gh run list --limit 5
```

Watch the newest run:

```bash
gh run watch
```

Once it succeeds, confirm your local repository is clean:

```bash
git status --short
```

No output means clean. Then create and push the release tag:

```bash
git tag -a notes-cli-v0.1.0 \
  -m "Notes CLI v0.1.0"

git push origin notes-cli-v0.1.0
```

So the order is:

```text
commit → push main → GitHub CI passes → create tag → push tag
```
