Run:

```zsh
sed -n '1,240p' pyproject.toml

find . \
  -maxdepth 3 \
  -type f \
  -print |
  sort

```

Also check whether Python can import the package:

```zsh
uv run python -c 'import notes_cli; print(notes_cli.__file__)'
```

The likely issue is that `uv init --app` created a non-packaged application. In that case, `uv` installs dependencies but does not create the `notes` executable.

If `pyproject.toml` has no `[build-system]` section, add:

```toml
[build-system]
requires = ["uv_build>=0.9.0,<0.10.0"]
build-backend = "uv_build"
```

Ensure this also exists:

```toml
[project.scripts]
notes = "notes_cli.cli:app"
```

Then rebuild the environment:

```zsh
uv sync --reinstall
uv run notes --help
```

Do not run `uv init` again yet—it could overwrite or conflict with the files you already created. If this still fails, send the `pyproject.toml` and file listing, and we’ll correct the exact structural mismatch.
