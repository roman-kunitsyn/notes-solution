You are using Zsh. In Zsh, `read -p` means “read from a coprocess”; it is not the Bash prompt option.

Use Zsh syntax:

```zsh
ROMAN_EMAIL="roman@example.test"
ALICE_EMAIL="alice@example.test"

read -rs 'ROMAN_PASSWORD?Roman password: '
printf '\n'

read -rs 'ALICE_PASSWORD?Alice password: '
printf '\n'
```

Verify that values were captured without printing the passwords:

```zsh
printf 'Roman password length: %d\n' "${#ROMAN_PASSWORD}"
printf 'Alice password length: %d\n' "${#ALICE_PASSWORD}"
```

Then continue with the login requests. When finished:

```zsh
unset ROMAN_PASSWORD ALICE_PASSWORD
```

In short:

- Bash: `read -rsp "Prompt: " VARIABLE`
- Zsh: `read -rs 'VARIABLE?Prompt: '`
