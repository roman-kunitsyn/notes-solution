Most likely you ran the command from the repository root. The uv project is inside `apps/notes-cli`, so uv must run from there.

Either:

```zsh
cd apps/notes-cli
uv run notes --help
```

Or, from the repository root:

```zsh
uv --directory apps/notes-cli run notes --help
```

If it still fails, synchronize the project:

```zsh
cd apps/notes-cli
uv sync
uv run notes --help
```

Then verify the entry point exists:

```zsh
sed -n '/^\[project.scripts\]/,/^\[/p' pyproject.toml
```

Expected:

```toml
[project.scripts]
notes = "notes_cli.cli:app"
```

Also confirm the module exists:

```zsh
find src/notes_cli -maxdepth 1 -type f -print
```

You should have:

```text
src/notes_cli/__init__.py
src/notes_cli/__main__.py
src/notes_cli/cli.py
```

If `pyproject.toml` has no `[build-system]` section, recreate the project as a packaged application:

```zsh
uv init --app --package .
```

But do this only if `[build-system]` is actually missing. The working directory is the most likely cause.
