That error is expected—the combined process is correct, but the current shell does not contain its required environment variables.

## 1. Get local Supabase values

From the repository root:

```bash
cd /Users/user/Desktop/personal-supabase

supabase status -o env
```

Find:

```text
API_URL="http://127.0.0.1:54321"
ANON_KEY="..."
```

Use `API_URL` as `SUPABASE_URL` and `ANON_KEY` as `SUPABASE_PUBLISHABLE_KEY`.

Do not use `SERVICE_ROLE_KEY`.

## 2. Export non-secret values

```bash
export SUPABASE_URL="http://127.0.0.1:54321"
export NOTES_BOT_BASE_URL="http://127.0.0.1:8080"
export NOTES_BOT_HTTP_HOST="127.0.0.1"
export NOTES_BOT_HTTP_PORT="8080"
```

The database path is optional. For an explicit local path outside the repository:

```bash
export NOTES_BOT_DATABASE_PATH="$HOME/Library/Application Support/notes-bot/notes-bot.sqlite3"
```

## 3. Enter secrets without shell-history exposure

For the BotFather token:

```zsh
read -s "TELEGRAM_BOT_TOKEN?Telegram bot token: "
echo
export TELEGRAM_BOT_TOKEN
```

For the local Supabase `ANON_KEY`:

```zsh
read -s "SUPABASE_PUBLISHABLE_KEY?Local Supabase anon key: "
echo
export SUPABASE_PUBLISHABLE_KEY
```

Paste each value when prompted.

## 4. Generate the encryption key

For this pre-authentication test, generate it in memory:

```bash
export NOTES_BOT_ENCRYPTION_KEY="$(
  uv run python -c \
    'from cryptography.fernet import Fernet; print(Fernet.generate_key().decode())'
)"
```

Once real sessions are stored, this key must remain stable across restarts. We will arrange persistent secret configuration before completing authentication.

## 5. Confirm variables without printing secrets

```bash
test -n "$TELEGRAM_BOT_TOKEN" \
  && echo "Telegram token configured"

test -n "$SUPABASE_PUBLISHABLE_KEY" \
  && echo "Supabase key configured"

test -n "$NOTES_BOT_ENCRYPTION_KEY" \
  && echo "Encryption key configured"
```

## 6. Run the combined process

```bash
uv run notes-bot
```

In another terminal:

```bash
curl -i http://127.0.0.1:8080/health
```

Expected:

```text
HTTP/1.1 200 OK
```

with:

```json
{ "status": "ok" }
```

Also verify `/start` in Telegram, then stop with `Ctrl+C`.

The configuration error requires no code change—it demonstrates that startup safely refuses to run with incomplete security configuration.
