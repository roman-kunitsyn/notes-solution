## Step 15 — Prepare challenge state for browser email OTP

For the first production-grade authentication flow, we will use email OTP inside the browser:

1. User opens the Telegram linking page.
2. Browser asks for their existing Supabase email.
3. Supabase sends an OTP.
4. User enters the OTP in the browser.
5. Supabase verifies it and returns a user session.
6. Only then is the Telegram challenge consumed.
7. The refresh token is encrypted and stored.

We will set `should_create_user=False`; the bot links existing Supabase accounts and does not silently create accounts.

Before adding network calls, SQLite must track:

- which email was selected;
- when an OTP was requested;
- failed verification attempts.

## 2. Add migration 2

In `database.py`, after `MIGRATION_1`, add:

```python
MIGRATION_2 = """
BEGIN;

ALTER TABLE link_challenges
    ADD COLUMN auth_email TEXT;

ALTER TABLE link_challenges
    ADD COLUMN otp_requested_at INTEGER;

ALTER TABLE link_challenges
    ADD COLUMN failed_attempts INTEGER
        NOT NULL
        DEFAULT 0
        CHECK (failed_attempts >= 0);

PRAGMA user_version = 2;

COMMIT;
"""
```

## 3. Update the migration runner

Replace `migrate_database()` with:

```python
def migrate_database(
    connection: sqlite3.Connection,
) -> None:
    version = connection.execute(
        "PRAGMA user_version"
    ).fetchone()[0]

    if version > SCHEMA_VERSION:
        raise DatabaseVersionError(
            "Database schema version "
            f"{version} is newer than supported version "
            f"{SCHEMA_VERSION}"
        )

    if version == 0:
        connection.executescript(MIGRATION_1)
        version = 1

    if version == 1:
        connection.executescript(MIGRATION_2)
```

This handles both cases:

```text
new database: 0 → 1 → 2
existing database: 1 → 2
```

Add this helper:

```python
def column_names(
    connection: sqlite3.Connection,
    table: str,
) -> set[str]:
    rows = connection.execute(
        f"PRAGMA table_info({table})"
    ).fetchall()

    return {
        str(row["name"])
        for row in rows
    }
```

The table name is controlled by the test, not user input.

Add:

```python
def test_link_challenges_has_auth_state(
    tmp_path: Path,
) -> None:
    path = tmp_path / "bot.sqlite3"

    with open_database(path) as connection:
        columns = column_names(
            connection,
            "link_challenges",
        )

    assert {
        "auth_email",
        "otp_requested_at",
        "failed_attempts",
    } <= columns
```

Add an explicit upgrade test:

```python
def test_open_database_upgrades_version_one(
    tmp_path: Path,
) -> None:
    path = tmp_path / "bot.sqlite3"

    connection = sqlite3.connect(path)
    connection.executescript(MIGRATION_1)
    connection.close()

    with open_database(path) as connection:
        version = connection.execute(
            "PRAGMA user_version"
        ).fetchone()[0]

        columns = column_names(
            connection,
            "link_challenges",
        )

    assert version == SCHEMA_VERSION
    assert {
        "auth_email",
        "otp_requested_at",
        "failed_attempts",
    } <= columns
```
