Next we add a production health check. It verifies container health, the HTTPS gateway, Auth, JWKS, and API-key enforcement without exposing secrets.

## 1. Create the health-check script

```zsh
nvim scripts/healthcheck.sh
```

Add:

```sh
#!/usr/bin/env sh

set -eu

cd "$(dirname "$0")/.."

ENV_FILE=".env.production"

SUPABASE_URL="$(
  sed -n 's/^SUPABASE_PUBLIC_URL=//p' "$ENV_FILE"
)"

if [ -z "$SUPABASE_URL" ]; then
  echo "SUPABASE_PUBLIC_URL is missing" >&2
  exit 1
fi

if printf '%s' "$SUPABASE_URL" | grep -q 'example\.com'; then
  echo "SUPABASE_PUBLIC_URL still contains a placeholder" >&2
  exit 1
fi

echo "Checking containers..."

docker compose \
  --env-file "$ENV_FILE" \
  --file docker-compose.yml \
  --file docker-compose.production.yml \
  --file docker-compose.caddy.yml \
  ps

echo "Checking Auth..."

curl --fail --silent --show-error \
  "$SUPABASE_URL/auth/v1/health" \
  >/dev/null

echo "Checking public JWKS..."

curl --fail --silent --show-error \
  "$SUPABASE_URL/auth/v1/.well-known/jwks.json" |
  jq -e '.keys | length > 0' \
  >/dev/null

echo "Checking API-key enforcement..."

STATUS="$(
  curl --silent \
    --output /dev/null \
    --write-out '%{http_code}' \
    "$SUPABASE_URL/rest/v1/"
)"

if [ "$STATUS" != "401" ]; then
  echo "Expected REST request without API key to return 401; received $STATUS" >&2
  exit 1
fi

echo "Production health check passed"
```

Make it executable:

```zsh
chmod +x scripts/healthcheck.sh
```

## 2. Run static checks now

The complete health check should currently stop at the placeholder-domain check. That is expected:

```zsh
scripts/healthcheck.sh
```

Check its shell syntax independently:

```zsh
sh -n scripts/healthcheck.sh
```

## 3. Test it against the local deployment

The script accepts its URL from `.env.production`, so don’t modify the production file. Create a temporary copy:

```zsh
cp .env.production /tmp/supabase-healthcheck.env

sed -i '' \
  's|^SUPABASE_PUBLIC_URL=.*|SUPABASE_PUBLIC_URL=http://127.0.0.1:8000|' \
  /tmp/supabase-healthcheck.env
```

For now, the script has `.env.production` fixed internally, so simply validate the individual local endpoints:

```zsh
curl --fail --silent --show-error \
  http://127.0.0.1:8000/auth/v1/health |
  jq

curl --fail --silent --show-error \
  http://127.0.0.1:8000/auth/v1/.well-known/jwks.json |
  jq '.keys | length'

curl --silent \
  --output /dev/null \
  --write-out 'HTTP status: %{http_code}\n' \
  http://127.0.0.1:8000/rest/v1/
```

Expected:

- Auth health succeeds;
- JWKS contains at least one public key;
- REST without an API key returns `401`.

## 4. Add it to the production command

In `scripts/production.sh`, add:

```sh
  health)
    scripts/healthcheck.sh
    ;;
```

And its help entry:

```sh
echo "  health     Run the production health check"
```

Validate both scripts:

```zsh
sh -n scripts/production.sh
sh -n scripts/healthcheck.sh
```

Commit when ready:

```zsh
git add scripts
git commit -m "Add production health checks"
```
