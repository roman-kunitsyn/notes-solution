## Step 5 — Add Notes bot to GitHub Actions

This CI job will verify:

- Python 3.14 installation;
- locked dependency synchronization;
- formatting;
- linting;
- unit tests;
- executable help;
- package build.

It must not use a Telegram token or connect to Telegram.

### 1. Update the CI workflow

Open:

```text
.github/workflows/ci.yml
```

Add this job at the same indentation level as `notes-cli` and `notes-integration`:

```yaml
notes-bot:
  name: Notes bot
  runs-on: ubuntu-24.04
  timeout-minutes: 10

  defaults:
    run:
      working-directory: apps/notes-bot

  steps:
    - name: Check out repository
      uses: actions/checkout@v5

    - name: Install uv
      uses: astral-sh/setup-uv@c771a70e6277c0a99b617c7a806ffedaca235ff9 # v9.0.0
      with:
        version: "0.12.7"
        enable-cache: true
        cache-dependency-glob: apps/notes-bot/uv.lock

    - name: Install Python
      run: uv python install

    - name: Synchronize locked dependencies
      run: uv sync --locked --all-groups

    - name: Check formatting
      run: uv run --frozen ruff format --check .

    - name: Run lint checks
      run: uv run --frozen ruff check .

    - name: Run unit tests
      run: uv run --frozen pytest

    - name: Verify bot entry point
      run: uv run --frozen notes-bot --help

    - name: Build package
      run: uv build
```

No `TELEGRAM_BOT_TOKEN` is provided. That is intentional: tests and `--help` must remain independent of external credentials.

### 2. Confirm the job placement

Their order is not important. The important part is that `notes-bot:` aligns with the other job names.

### 4. Review for accidental secrets

From the repository root:

```bash
git status --short
git diff --check
git diff -- .github/workflows/ci.yml
```

Search only the files being added:

```bash
git diff --no-index /dev/null apps/notes-bot/.env.example
```

The example must contain an empty value:

```dotenv
TELEGRAM_BOT_TOKEN=
```

Confirm the real token is not present in tracked or untracked text files:

```bash
git grep -n "TELEGRAM_BOT_TOKEN"
```

It is normal to see:

- `config.py`
- tests
- `.env.example`
- documentation

You should only see the variable name—never the actual token.
