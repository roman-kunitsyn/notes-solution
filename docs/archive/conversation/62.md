4. Command reference and examples

The release boundary is:

```text
v0.1.0
├── persistent configuration
├── login, logout and whoami
├── note CRUD
├── editor workflows
├── private attachments
├── friendly errors
├── unit tests
├── two-user integration tests
└── CI
```

After tagging it, we begin:

```text
apps/notes-bot/
```

At that moment, we will have two Python consumers. That gives us a real reason to extract reusable Supabase operations from the CLI into:

```text
packages/notes-python/
```

The intended dependency direction will be:

```text
apps/notes-cli ─┐
                ├── packages/notes-python ── Supabase
apps/notes-bot ─┘
```

The shared package will contain note and attachment operations, but not Typer commands, Telegram handlers, or local CLI session files.
