VS Code is warning correctly if it thinks the project supports Python earlier than 3.14. Ruff generated valid Python 3.14 syntax, but it is unnecessarily restrictive for this CLI.

I recommend targeting Python 3.12+, rather than making the CLI require 3.14.

Check the current configuration:

```bash
rg 'requires-python|target-version' pyproject.toml
```

In `apps/notes-cli/pyproject.toml`, use:

```toml
[project]
requires-python = ">=3.12"
```

And add or update:

```toml
[tool.ruff]
target-version = "py312"
```

Then run:

```bash
uv lock
uv run ruff format .
```

Ruff should restore the compatible syntax:

```python
except (ValueError, UnicodeDecodeError, json.JSONDecodeError):
    return None
```

Verify everything:

```bash
uv run ruff format --check .
uv run ruff check .
uv run pytest
```

Also ensure VS Code uses the project environment:

1. Open the Command Palette.
2. Select **Python: Select Interpreter**.
3. Choose:

```text
apps/notes-cli/.venv/bin/python
```

Commit all resulting changes, including the lockfile:

```bash
cd ../..

git add \
  apps/notes-cli/pyproject.toml \
  apps/notes-cli/uv.lock \
  apps/notes-cli/src/notes_cli/config.py

git commit -m "Support Notes CLI on Python 3.12"
git push origin main
```

This resolves the VS Code warning while keeping the CLI usable beyond Python 3.14.
