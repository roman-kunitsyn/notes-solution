Use Typer’s modern `Annotated` syntax. Add:

```python
from typing import Annotated
```

Replace the `download` signature with:

```python
@app.command()
def download(
    note_id: str,
    filename: str,
    output: Annotated[
        Path | None,
        typer.Option(
            "--output",
            "-o",
            help="Destination path. Defaults to the attachment filename.",
        ),
    ] = None,
    force: Annotated[
        bool,
        typer.Option(
            "--force",
            help="Overwrite an existing local file.",
        ),
    ] = False,
) -> None:
```

The rest of the function remains unchanged.

Why this fixes it:

```python
# Old: function call used as a default
output: Path | None = typer.Option(...)

# New: CLI metadata is in the annotation
output: Annotated[Path | None, typer.Option(...)] = None
```

Run:

```zsh
uv run ruff format .
uv run ruff check .
uv run pytest
uv run notes download --help
```

If Ruff reports the same warning for other Typer parameters, migrate those signatures to `Annotated` using the same pattern. This is the preferred style for the whole CLI.
