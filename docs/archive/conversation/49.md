Replace `get_note()` in `notes.py` with a normal query returning at most one row:

```python
def get_note(note_id: str) -> Note | None:
    client = authenticated_client()

    response = (
        client.table("notes")
        .select(NOTE_COLUMNS)
        .eq("id", note_id)
        .limit(1)
        .execute()
    )

    if not response.data:
        return None

    return Note.from_row(response.data[0])
```

- owned note exists → one row;
- note is missing → empty list;
