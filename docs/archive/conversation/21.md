The problem came from this earlier command:

```bash
set -a
source .env
set +a
```

Shell parsing removed JSON quotes from `JWT_JWKS`. Because shell variables override Compose’s `.env`, Storage received invalid JSON.

## Fix the current shell

First confirm the value stored in the file itself is valid without displaying it:

```bash
sed -n 's/^JWT_JWKS=//p' .env |
  jq -e . >/dev/null &&
  echo "JWT_JWKS in .env is valid"
```

Now remove only the damaged exported version:

```bash
unset JWT_JWKS
```

Recreate Storage:

```bash
docker compose up -d --force-recreate storage
```

Watch startup:

```bash
docker compose logs -f storage
```

Stop following logs with `Ctrl-C` once Storage starts successfully.

Check health:

```bash
docker compose ps storage
```

## Confirm both fixes

Verify that Storage received valid JSON:

```bash
docker inspect supabase-storage \
  --format '{{range .Config.Env}}{{println .}}{{end}}' |
  sed -n 's/^JWT_JWKS=//p' |
  jq -e . >/dev/null &&
  echo "Container JWT_JWKS is valid"
```

Verify that `/var/lib/storage` uses a named volume:

```bash
docker inspect supabase-storage \
  --format '{{range .Mounts}}{{println .Type .Name "->" .Destination}}{{end}}'
```

Expected:

```text
volume ... -> /var/lib/storage
```

Then retry the upload:

```bash
curl --fail-with-body -sS \
  -X POST "$SUPABASE_URL/storage/v1/object/note-attachments/$ATTACHMENT_PATH" \
  -H "apikey: $ANON_KEY" \
  -H "Authorization: Bearer $ROMAN_TOKEN" \
  -H "Content-Type: text/plain" \
  --data-binary @/tmp/example.txt
```

For future work, do not `source .env`. It is a Docker environment file, not necessarily a valid shell script. Docker Compose reads it automatically. For one simple value, extract it without evaluating the file:

```bash
ANON_KEY="$(sed -n 's/^ANON_KEY=//p' .env)"
```

Docker documents that exported shell variables take precedence over values read from `.env`, which is why the malformed exported value won: [Compose variable interpolation and precedence](https://docs.docker.com/compose/how-tos/environment-variables/variable-interpolation/).
