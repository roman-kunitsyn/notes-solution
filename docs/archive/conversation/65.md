CI failed only because Ruff formatting was not applied. `ruff check` and `ruff format --check` are separate checks.

From `apps/notes-cli`, run:

```bash
uv run ruff format .
uv run ruff format --check .
uv run ruff check .
uv run pytest
```

Inspect the formatting change:

```bash
git diff -- src/notes_cli/config.py
```

Ruff may remove parentheses from the multi-exception clause because Python 3.14 supports that syntax.

Commit and push the correction:

```bash
cd ../..

git add apps/notes-cli/src/notes_cli/config.py
git commit -m "Format Notes CLI source"
git push origin main
```

Then watch the new GitHub Actions run:

```bash
gh run watch
```

Do not create the release tag yet. Wait until the new run has a green check mark.
