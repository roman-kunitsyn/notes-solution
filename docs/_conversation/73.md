## Step 1 — Initialize the Notes bot package

The goal of this step is only to create a clean Python 3.14 application with locked dependencies. We will not implement Telegram handlers or Supabase authentication yet.

From the monorepo root:

```bash
cd /Users/user/Desktop/personal-supabase

git status --short
```

The command should produce no output. If it shows changes, stop and show them to me before continuing.

Initialize the packaged application:

```bash
uv init \
  --app \
  --package \
  --python 3.14 \
  apps/notes-bot
```

Enter the new application:

```bash
cd apps/notes-bot
```

Add the runtime dependency:

```bash
uv add "aiogram>=3.23.0,<4"
```

We use aiogram because it explicitly supports Python 3.14. The `<4` boundary protects the project from an automatic future major-version upgrade.

Add development dependencies:

```bash
uv add --dev \
  "pytest>=9.1.1,<10" \
  "pytest-asyncio>=1.3.0,<2" \
  "ruff>=0.16.5,<0.17"
```

Confirm the environment:

```bash
uv run python --version
uv tree
```

Then show me:

```bash
find . \
  -maxdepth 3 \
  -type f \
  -not -path './.venv/*' \
  | sort

sed -n '1,240p' pyproject.toml

git status --short
```

Do not edit the generated Python files yet. Send me the output, and we’ll review the package structure before implementing `/start`.
