Let’s scaffold one independent Python application inside the Git repository. We will not introduce a uv workspace or shared package yet; `notes-cli` gets its own `pyproject.toml`, environment, and lockfile.

## 1. Create the application

From the repository root:

```zsh
mkdir -p apps

uv init \
  --app \
  apps/notes-cli
```

Confirm uv did not create a nested Git repository:

```zsh
test ! -d apps/notes-cli/.git &&
  echo "Using parent Git repository"
```

Inspect the result:

```zsh
find apps/notes-cli \
  -maxdepth 3 \
  -type f |
  sort
```

## 2. Add dependencies

```zsh
cd apps/notes-cli

uv add \
  typer \
  supabase \
  platformdirs

uv add --dev \
  pytest \
  ruff
```

Why these dependencies:

- `typer`: CLI commands and help;
- `supabase`: Auth, database and Storage client;
- `platformdirs`: correct macOS/Linux configuration directory;
- `pytest`: tests;
- `ruff`: linting and formatting.

`uv.lock` records the exact resolved versions.

## 3. Configure the CLI entry point

Open:

```zsh
nvim pyproject.toml
```

Ensure it contains an executable entry:

```toml
[project.scripts]
notes = "notes_cli.cli:app"
```

The generated package directory should be:

```text
src/notes_cli/
```

Create `src/notes_cli/cli.py`:

```python
import typer

app = typer.Typer(
    name="notes",
    help="Personal notes client for self-hosted Supabase.",
    no_args_is_help=True,
)


@app.command()
def version() -> None:
    """Show the Notes CLI version."""
    typer.echo("notes-cli 0.1.0")


if __name__ == "__main__":
    app()
```

Create `src/notes_cli/__main__.py`:

```python
from notes_cli.cli import app

app()
```

## 4. Add the application instructions

Create:

```zsh
nvim AGENTS.md
```

Add:

````markdown
# Notes CLI instructions

## Scope

This directory contains the Python command-line client for the Notes application.

## Architecture

- `cli.py` defines commands and presentation.
- Supabase operations belong in client/service modules.
- Configuration and session persistence belong in dedicated modules.
- Command functions should remain small.
- The database schema is owned by the repository-level `supabase/` directory.

## Security

- Use only `SUPABASE_PUBLISHABLE_KEY`.
- Never use or expose `SUPABASE_SECRET_KEY` or `SERVICE_ROLE_KEY`.
- Do not send `user_id` when creating owned records.
- Let PostgreSQL and RLS determine ownership through `auth.uid()`.
- Store sessions outside the repository with restrictive permissions.
- Never print access or refresh tokens.

## Dependencies

- Manage dependencies with uv.
- Commit `pyproject.toml` and `uv.lock`.
- Do not install dependencies with raw `pip`.
- Do not create a shared package until another real application needs it.

## Validation

Run before completing changes:

```sh
uv run ruff format --check .
uv run ruff check .
uv run pytest
uv run notes --help
```

## 5. Add a first test

Create:

```zsh
mkdir -p tests
nvim tests/test_cli.py
````

Add:

```python
from typer.testing import CliRunner

from notes_cli.cli import app

runner = CliRunner()


def test_version() -> None:
    result = runner.invoke(app, ["version"])

    assert result.exit_code == 0
    assert result.stdout == "notes-cli 0.1.0\n"
```

## 6. Verify the scaffold

```zsh
uv run notes --help
uv run notes version

uv run ruff format .
uv run ruff check .
uv run pytest
```

Expected:

```text
notes-cli 0.1.0
```

and one passing test.

## 7. Return to the root and commit

```zsh
cd ../..

git status --short
git diff --check

git add apps/notes-cli
git commit -m "Scaffold Notes CLI application"
```

The repository now has the correct initial boundary:

```text
supabase/           server contract
deploy/             operations
apps/notes-cli/     first real client
```

The next implementation slice is configuration plus `login`, `logout`, and `whoami`, tested against your local self-hosted Supabase.
